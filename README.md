# 🎯 Overview

Tic-Tac-Toe Arena is an interactive browser-based implementation of the classic Tic-Tac-Toe game built using **HTML**, **CSS**, and **JavaScript**.

Players take turns placing their symbols (**X** and **O**) on a 3×3 board while the game continuously checks for winning combinations and draw conditions. The game provides instant feedback and allows users to restart matches at any time.

# ⚔️ How To Play

### Step 1

Player **X** starts the game.

---

### Step 2

Player **O** takes the next turn.

---

### Step 3

Players alternate turns until:

* A player wins
* The board fills completely

---

### Step 4

The game automatically checks for:

```text
Winning Row
Winning Column
Winning Diagonal
```

---

### Step 5

Restart anytime to play again.

---

# 🧠 Game Logic

```text
Player Clicks Cell
          ↓
Cell Updated
          ↓
Check Winning Pattern
          ↓
Winner Found?
     ↙         ↘
   Yes          No
    ↓            ↓
Declare      Check Draw
Winner           ↓
            Continue Game
```
